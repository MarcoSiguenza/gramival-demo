# GramiVal Demo

Sistema demostrativo para la gestión y generación de cotizaciones de grama sintética.

Este proyecto fue desarrollado como una demostración funcional para validar la viabilidad de un sistema integral de cotizaciones, administración de precios y seguimiento de ventas para una empresa dedicada a la instalación de grama sintética.

---

## Características

- Inicio de sesión con roles.
- Panel para Administrador y Vendedor.
- Generación de cotizaciones mediante un asistente (Wizard).
- Administración de precios por departamento y zona.
- Catálogo de tipos de grama.
- Historial de cotizaciones.
- Dashboard con indicadores principales.
- Datos simulados para demostración.

## Cómo ejecutar el proyecto

1. Clonar el repositorio.

```bash
git clone https://github.com/TU_USUARIO/gramival-demo.git
```

2. Entrar al proyecto.

```bash
cd gramival-demo
```

3. Abrir `index.html` en cualquier navegador moderno.

No requiere se necesita ninguna dependencia ni servidor.

---

## Objetivo del proyecto

El objetivo es desarrollar una solución que permita a los vendedores generar cotizaciones de manera rápida y precisa considerando variables como:

- Departamento
- Municipio
- Tipo de grama
- Metros cuadrados
- Zona urbana/rural
- Costos de transporte
- Estado de la cotización
